# Plan: 3.13 AirQR Optical Air-Gapped Animated QR Code Sync

**Status:** Proposed

## Overview
Implement serverless, optical air-gapped data transfer between nearby devices using screen-to-camera animated QR code streams (5–25 FPS), Luby Transform (LT) Fountain codes with systematic parity frames, CRC32 checksum verification, and an interactive task import preview sheet.
