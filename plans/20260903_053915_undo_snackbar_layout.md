# Fix the empty space in the undo SnackBar

**Status:** completed

## The issue

In the screenshot (Malayalam UI) the undo message box looks wrong:

- The message text sits on the first line.
- The "പഴയപടിയാക്കുക" (Undo) button drops to a second line, pushed to the right.
- The close (X) icon sits at the far right of that second line.
- The result is a tall box with a lot of empty space on the left and in the middle.

Why it happens: Flutter's `SnackBar` moves the action button to its own
second line when the action label is wider than `actionOverflowThreshold`
(default 25%) of the SnackBar width. The Malayalam label is long, so it always
overflows and forces the two-line layout. The close icon is also always on,
which eats more width and adds to the emptiness.

## Files to change

- `lib/presentation/shared/widgets/undo_status_snackbar.dart`
- `lib/presentation/shared/theme/app_theme.dart`
- `lib/l10n/app_ml.arb`
- `lib/l10n/app_localizations_ml.dart` (regenerated by `flutter gen-l10n`)

## The plan

1. **Keep the action on one line.** In `showUndoSnackBar`, set
   `actionOverflowThreshold: 1.0` on the `SnackBar` so the undo button stays
   beside the message instead of dropping to a second line.
2. **Drop the close icon on this SnackBar.** Set `showCloseIcon: false` for the
   undo SnackBar only. The undo action plus the 5 second timeout plus
   swipe-to-dismiss are enough, and the icon is what leaves the extra gap.
   The app-wide `snackBarTheme` keeps `showCloseIcon: true` for other messages.
3. **Tidy the padding.** Give the undo SnackBar a small explicit
   `padding` (left padding for the text, less on the action side) so the text
   and the button are balanced.
4. **Shorten the Malayalam undo label** from `പഴയപടിയാക്കുക` to `പഴയപടി`
   ("undo" in short form) in `lib/l10n/app_ml.arb`, then regenerate the
   localization files. A shorter label keeps the one-line layout comfortable
   even for long messages.
5. **Also widen the threshold in the theme** (`actionOverflowThreshold: 1.0` in
   `snackBarTheme`) so other SnackBars with long translated action labels do
   not hit the same problem.
