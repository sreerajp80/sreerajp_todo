# Implementation Plan - 3.14 Serverless Encrypted Local P2P Wi-Fi Sync Engine

**Status:** Proposed

## Problem / Requirement
Implement Feature 3.14 (Serverless Encrypted Local P2P Wi-Fi Sync Engine) from `docs/unique_features_and_improvements.md`.
The feature provides direct device-to-device task and timecard synchronization over local Wi-Fi / hotspot connections without external servers or cloud dependencies.

Key components required:
1. **Serverless Local TCP Transport**: Temporary TCP server socket on host device on random local port (`ServerSocket.bind`), peer client connection via IP/port.
2. **High-Entropy Session Encryption**: PBKDF2-HMAC-SHA256 (300,000 iterations) key derivation from out-of-band 6-digit numeric pairing PIN or QR code, securing TCP payload communication with authenticated encryption.
3. **Connect-Then-Choose Workflow**: Authenticated peer pairing, interactive selection of sync scope (Full Sync, Today's Tasks, Time Segments, Recurrence Rules, Mastery Deck).
4. **Add-Only Non-Destructive Merge**: Natural primary key (`date` + NFC-normalized `title`) merging without overwriting local data or violating past-day Day-Lock rules.
5. **Hardened Security & Bounds**: Strict caps (`MAX_TODOS = 10000`, `MAX_FIELD_LEN = 4KB`, 30s handshake timeout, 120s host idle auto-stop).

## Proposed Files to Change / Create

### New Files
- `lib/domain/entities/p2p_sync_scope.dart`: Enum and data model for sync scope choices (Full Sync, Today's Tasks, Time Segments, Recurrence Rules, Mastery Deck).
- `lib/domain/entities/p2p_sync_payload.dart`: Data structures for serializing and deserializing sync packages and merge result statistics.
- `lib/data/services/p2p_wifi_sync_crypto.dart`: Cryptographic session engine using PBKDF2-HMAC-SHA256 (300,000 iterations) key derivation and AES-256 CTR + HMAC payload encryption.
- `lib/data/services/p2p_wifi_sync_service.dart`: TCP transport service implementing host listening, peer client connection, handshake authentication, memory bounds enforcement, and non-destructive merge into SQLite DAOs.
- `lib/presentation/screens/p2p_wifi_sync/p2p_wifi_sync_screen.dart`: UI screen with Host & Peer mode tabs, PIN / QR code display, sync scope selector, live progress, and merge summary sheet.
- `test/data/services/p2p_wifi_sync_crypto_test.dart`: Unit tests for encryption, key derivation, and auth tag validation.
- `test/data/services/p2p_wifi_sync_service_test.dart`: Unit tests for payload bounds enforcement, NFC title normalization, Day-Lock preservation, and non-destructive merge logic.
