# Fix swapped times in the target progress label

**Status:** completed

## Issue

On a task tile with a target time, the label under the task shows the two times in the
wrong order. For example, a task with 00:29:00 tracked against a 00:30:00 target shows
"00:30:00 of 00:29:00". It should show "00:29:00 of 00:30:00".

Root cause: the generated localization method is
`targetProgressLabel(String target, String tracked)` (the argument order comes from the
placeholder order in `app_en.arb`). The tile calls it as
`targetProgressLabel(formatDuration(trackedSeconds), formatDuration(targetSeconds))`,
so the two values are swapped. This affects all three languages.

The wording can also be clearer, so the meaning "29 minutes out of a 30 minute total"
is plain in every language.

## Files to change

- `lib/presentation/screens/daily_list/widgets/todo_list_tile.dart` — pass the values in
  the correct order (target first, tracked second).
- `lib/l10n/app_en.arb` — clearer wording and a better `@` description.
- `lib/l10n/app_ml.arb` — clearer wording.
- `lib/l10n/app_sa.arb` — clearer wording (classical Sanskrit).
- `lib/l10n/app_localizations*.dart` — regenerated by `flutter gen-l10n` (not edited by hand).
- A widget test for the tile label (new or existing tile test) — checks that the tracked
  time comes first and the target second.

## Fix

1. Swap the arguments in `todo_list_tile.dart` so `target` gets the target time and
   `tracked` gets the tracked time.
2. Update the strings (example: tracked 00:29:00, target 00:30:00):

   | Lang | New string | Shows as |
   |------|-----------|----------|
   | en | `{tracked} out of {target}` | 00:29:00 out of 00:30:00 |
   | ml | `ആകെ {target}-ൽ {tracked}` | ആകെ 00:30:00-ൽ 00:29:00 ("of a total 00:30:00, 00:29:00") |
   | sa | `आहत्य {target} मध्ये {tracked}` | आहत्य 00:30:00 मध्ये 00:29:00 ("in total 00:30:00, of that 00:29:00") |

   Update the `@targetProgressLabel` description to say: "{tracked} is time already spent,
   {target} is the total target time."
3. Run `flutter gen-l10n`, `dart format`, `flutter analyze`, and `flutter test`.
4. Write a change log.
