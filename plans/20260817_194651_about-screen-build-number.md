# Show the build number on the About screen

**Status:** completed

## The issue

The About screen shows the version (`1.9.2`) but never shows the build number.

- `assets/config/app_config.json` has `"build": "17"`.
- `lib/core/config/app_config.dart` parses it into `AppConfig.build`.
- `lib/presentation/screens/about/about_screen.dart` never uses `config.build`.

So the value is loaded and then thrown away. The screenshot confirms it: there is a
"Version" row and a "Build date" row, but no build number anywhere.

Side note (found while checking): `lib/core/constants/app_version.g.dart` holds
`kAppVersion = '1.9.2+17'`, generated from `pubspec.yaml`. It is currently used
nowhere in the app. See "Option B" below.

## The plan for the fix

Add a new "Build" row to the About details card, right under "Version", showing
`config.build`. Only show the row when the build value is not empty.

This needs a new user-visible label, so a new string goes into both language files.

### Files to change

| File | Change |
|------|--------|
| `lib/l10n/app_en.arb` | Add `aboutBuildNumber` = "Build" with its `@` description |
| `lib/l10n/app_ml.arb` | Add the Malayalam label for `aboutBuildNumber` |
| `lib/l10n/app_localizations*.dart` | Regenerated by `flutter gen-l10n` (not hand edited) |
| `lib/presentation/screens/about/about_screen.dart` | Add the `_AboutDetailRow` for the build number |

### Steps

1. Add `aboutBuildNumber` to `app_en.arb` and `app_ml.arb`.
2. Run `flutter gen-l10n` to regenerate the localization Dart files.
3. In `about_screen.dart`, after the Version row, add:
   - a 12 dp spacer and an `_AboutDetailRow` with icon `Icons.tag_rounded`,
     label `context.l10n.aboutBuildNumber`, value `config.build`,
   - wrapped in a check so it is skipped when `config.build` is empty.
4. Run `flutter analyze` (must be 0 issues) and `flutter test`.
5. Write the change log in `change_log/`.

### Layer check

Presentation layer only, plus localization resources. No domain, data, or database
change. No new dependency. Nothing offline-related is touched.

## Alternatives considered

**Option A (simpler, no new string):** show the version row value as `1.9.2 (17)`.
Fewer files, but the build number is less obvious and cannot be read on its own.

**Option B (more robust, bigger change):** drop `version`/`build` from
`app_config.json` and read `kAppVersion` from `app_version.g.dart`, which is
generated from `pubspec.yaml`. This removes the risk of the config file drifting
out of sync with the real build. It touches `AppConfig`, the JSON asset, the About
screen, and any config tests, so it is a separate change if wanted.

The main plan above is the recommended one. Say the word if you prefer A or B.
