# OCR Task Name and Description Scanner Implementation Plan

**Status:** Implemented
**Date:** 2026-09-11

## Issue
The app currently supports manual task entry and offline voice task input. The user requested implementing **OCR for task name and description**:
- Text structure: Two parts separated by space (blank line), hash (`#`), or dashed line (`---`).
- First line is the task name.
- Everything after the separator is the description.
- The OCR camera should provide advanced features to users.
- Operation must remain 100% offline with zero cloud/network dependencies in accordance with project engineering and security rules.

## Proposed Changes

### 1. Offline Dependencies
Add approved local-only packages to `pubspec.yaml`:
- `camera`: Flutter official camera plugin for custom viewfinder, zoom, flash/torch, tap-to-focus, and photo capture.
- `google_mlkit_text_recognition`: On-device text recognition v2 engine (runs locally on hardware, 0 network access).
- Transitive dependency check and verification against prohibited categories.
- Update `docs/dependencies.md` to register `camera` and `google_mlkit_text_recognition`.

### 2. Core Domain / Utility: OCR Task Parser
Create `lib/core/utils/ocr_task_parser.dart` and `lib/domain/entities/ocr_task_result.dart`:
- `OcrTaskResult`: Immutable model containing `title`, `description`, `rawText`, and `hasSeparator`.
- `OcrTaskParser.parse(String rawText)`:
  - Trims and normalizes line breaks.
  - Identifies separator line matching:
    - Blank line (space / whitespace line)
    - Hash line (line composed of `#` characters, e.g. `#`, `##`, `###`, etc.)
    - Dashed line (line composed of `-`, `_`, or `=`, e.g. `---`, `___`, `===`, `- - -`)
  - Line before separator (first non-empty line) becomes the **Task Name**.
  - All lines after the separator become the **Description** (joined by newlines).
  - If no separator is detected:
    - Line 1 becomes the Task Name.
    - Lines 2..N become the Description.
    - If only 1 line exists, Description is empty.
  - Applies Unicode NFC normalization (`unicodeUtils.nfcNormalize`) to both title and description.

### 3. Advanced OCR Camera Screen
Create `lib/presentation/screens/ocr/ocr_scan_screen.dart` and supporting widgets in `lib/presentation/screens/ocr/widgets/`:
- **Advanced Camera Viewfinder**:
  - Full-screen live camera preview with aspect-ratio management.
  - Document framing overlay with transparent cutout mask and high-contrast corner reticles.
  - Visual guides indicating "Task Name (Line 1)" and "Description (After space / # / ---)".
- **Camera Controls**:
  - Torch / Flash toggle (Cycle between Auto, Always On / Torch, Off).
  - Camera switch (Front / Back camera toggling).
  - Smooth pinch-to-zoom and quick zoom preset buttons (`1x`, `2x`).
  - Tap-to-focus with animated indicator ring.
  - Photo capture shutter button.
  - Gallery import button (pick an existing photo or document via `file_picker`).
- **Interactive Review Bottom Sheet (`OcrResultBottomSheet`)**:
  - Displays parsed Task Name in an editable text field (with real-time title uniqueness check).
  - Displays parsed Description in an editable multi-line text field.
  - Expandable "Raw OCR Text" tile with one-tap copy button.
  - Quick action buttons:
    - "Create Task" (instantly saves the task to the current date).
    - "Open in Full Editor" (navigates to `CreateEditTodoScreen` with title & description pre-filled).
    - "Retake / Scan Again" (resumes camera).
- **Graceful Error & Permission Handling**:
  - Explains camera permission requirement with system settings fallback if denied.
