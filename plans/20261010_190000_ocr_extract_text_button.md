# OCR: extract text only on button tap

**Status:** completed

## Issue

On the "Enhance & Scan" screen (`lib/presentation/screens/ocr/ocr_enhance_screen.dart`),
text recognition (OCR) runs by itself:

- right after the photo is prepared,
- after every rotate, crop, filter, brightness/contrast change and invert,
- after every language change.

This wastes work while the user is still editing, and the text shown may come from an
image the user has not finished fixing. The user wants OCR to run **only** when they
tap a new **Extract text** button, after all edits are done. The button must be
icon-only, with a tooltip and no text label.

## Files to change

1. `lib/presentation/screens/ocr/ocr_enhance_screen.dart`
2. `lib/l10n/app_en.arb`
3. `lib/l10n/app_ml.arb`

6. `test/presentation/screens/ocr/ocr_enhance_screen_test.dart`

## Plan for the fix

### 1. Stop automatic OCR (`ocr_enhance_screen.dart`)

- `_applyEnhancements()` will only make the enhanced image and preview. It will no
  longer call OCR at the end.
- `_onLanguageChanged()` will only store the new language. It will not start OCR.
- Every edit (rotate, crop, filter, brightness, contrast, reset, invert, language) will:
  - cancel any OCR run still in progress (its result would be for an old image),
  - clear the recognised text and word count,
  - so the "Use Text" button is disabled until the user extracts again.
- Add a small "generation" counter to `_applyEnhancements()` so that if two enhance
  runs overlap, only the newest result is kept. This makes sure Extract always reads
  the image that matches the current edits.

### 2. Add the Extract text button

- In the app bar, just before the "Use Text" button, add an `IconButton`:
  - key `ocr-enhance-extract-btn`,
  - icon `Icons.document_scanner`,
  - `tooltip: l10n.ocrExtractTextTooltip`,
  - no label.
- It is disabled while the photo is being prepared, while an enhancement is running,
  or while OCR is already running.
- On tap (`_extractText()`):
  - if an edit is still waiting in the 250 ms debounce timer, cancel the timer and run
    the enhancement now, then wait for it to finish;
  - run OCR on the latest enhanced image (or the master if there is none) with the
    selected language;
  - show the text and word count in the panel, as today.

### 3. Text panel wording

- Track whether text has been extracted for the current edits (`_hasExtracted`).
- Before extraction: the panel shows a new hint, "Finish editing, then tap the scan
  button to read the text." The word-count badge is hidden.
- While reading: badge shows "Reading..." (existing key).
- After extraction with no text: shows the existing "Nothing read yet..." message and
  "No text found" badge, as today.
- Rename `_runLiveOcr` to `_runOcr` and update the class doc comment (no more "live").

### 4. New localized strings (all three languages, with `@key` descriptions)

| Key | English |
|-----|---------|
| `ocrExtractTextTooltip` | Extract text |
| `ocrEnhanceExtractHint` | Finish editing, then tap the scan button to read the text. |

Malayalam and classical Sanskrit (no Hindi words) translations will be added. Then run
`flutter gen-l10n`.

### 5. Tests (`ocr_enhance_screen_test.dart`)

- Give the fake OCR service a call counter.
- New tests:
  - OCR does not run when the screen opens.
  - Rotate / filter edits do not run OCR.
  - Tapping the extract button runs OCR once and shows the text; "Use Text" becomes
    enabled.
  - An edit after extraction clears the text and disables "Use Text".
- Keep the three existing crop/master tests working.
