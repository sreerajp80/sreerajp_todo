# Plan: Upgrade the Kotlin Gradle Plugin to 2.4.10

**Status:** completed

## What the issue is

The Android build uses the Kotlin Gradle Plugin (KGP) 2.2.20. After the Flutter 3.47.6 /
AGP 9.4.1 upgrade (plan `plans/20261011_072244_toolchain_upgrade_flutter_3_47_agp_9.md`),
every Android build prints this warning:

> Flutter support for your project's Kotlin version (2.2.20) will soon be dropped. Please
> upgrade your Kotlin version to a version of at least 2.3.20 soon.

The target is KGP **2.4.10**.

## Files to be changed

| File | Change |
|------|--------|
| `android/settings.gradle.kts` | `id("org.jetbrains.kotlin.android") version "2.2.20"` → `"2.4.10"`. |

That is the only place the Kotlin version is set. No doc in the project names the Kotlin
version, so no doc change is needed.

## Plan for the fix

1. Change the version in `android/settings.gradle.kts`.
2. Keep `android.builtInKotlin=false` and `android.newDsl=false` in `android/gradle.properties`.
   The app still applies Kotlin through the `kotlin-android` plugin id.
3. Check:
   - `flutter build apk --flavor dev --debug` (compiles the app's Kotlin code: OCR, QR and
     other platform-channel files),
   - the Android unit test for `OcrReadingOrder.kt` (`gradlew :app:testDevDebugUnitTest`),
   - `flutter analyze` and `flutter test` (Dart side, should be unchanged).
4. If Kotlin 2.4 reports new errors or deprecation failures in the app's Kotlin files, fix only
   those and list them in the change log.
5. Write the change log and set this plan to `completed`.

## Not in this plan

The build also warns that the app should migrate to "Built-in Kotlin" (AGP 9 compiles Kotlin
itself, so the separate Kotlin plugin is dropped and `android.builtInKotlin=false` is
removed). That is a bigger change and can be its own plan.
