# Change Log: Kotlin Gradle Plugin upgraded to 2.4.10

Implements plan: [plans/20261011_080434_kotlin_2_4_10_upgrade.md](../plans/20261011_080434_kotlin_2_4_10_upgrade.md)

## What changed

- `android/settings.gradle.kts`: `org.jetbrains.kotlin.android` `2.2.20` → `2.4.10`.

No other file changed. The app's Kotlin source compiled on 2.4.10 without any code change.
`android.builtInKotlin=false` and `android.newDsl=false` stay in `android/gradle.properties`.

## Result

The build no longer prints "Flutter support for your project's Kotlin version (2.2.20)
will soon be dropped".

## Verification

- `flutter build apk --flavor dev --debug`: built.
- `gradlew :app:testDevDebugUnitTest`: passed (`OcrReadingOrderTest` 8 tests,
  `QrFrameDecoderTest` 6 tests, 0 failures).
- `flutter analyze`: no issues.
- `flutter test`: all 864 tests passed.

## Notes

- The first build attempt failed because the Gradle daemon left from an earlier build ran out
  of system memory (a JVM "insufficient memory" crash, not a Kotlin error). After stopping the
  old daemons with `gradlew --stop`, the build passed. The JVM crash log file it wrote was
  deleted and not committed.
- Still open (separate plan): the build warns that the app applies the Kotlin Gradle Plugin
  and should migrate to Built-in Kotlin.
