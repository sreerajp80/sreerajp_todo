# Change Log - 3.14 Serverless Encrypted Local P2P Wi-Fi Sync Engine

**Plan Reference:** [plans/20260811_195100_wifi_sync_engine.md](file:///l:/Android/sreerajp_todo/plans/20260811_195100_wifi_sync_engine.md)

## Summary of Changes
Implemented Feature 3.14 (Serverless Encrypted Local P2P Wi-Fi Sync Engine) for direct device-to-device task and timecard synchronization across local Wi-Fi / hotspot connections without cloud servers or third-party backends.

Key features added:
1. **P2P Sync Domain Models & Scope**:
   - `P2pSyncScope`: Support for selective scope synchronization (Full Sync, Today's Tasks, Time Segments, Recurrence Rules, Mastery Deck).
   - `P2pSyncPayload`: Serialized sync bundle with bounds enforcement (`maxTodos = 10000`, `maxFieldLen = 4KB`).
   - `P2pSyncMergeResult`: Statistics and counts for imported and skipped records.

2. **Session Encryption & TCP Socket Transport**:
   - `P2pWifiSyncCrypto`: Key derivation via PBKDF2-HMAC-SHA256 (300,000 iterations) from an out-of-band 6-digit numeric pairing PIN or QR code payload (`wifi_sync://<ip>:<port>?pin=<pin>&salt=<salt_hex>`), protecting TCP socket payload communication with AES-256 CTR + HMAC-SHA256 authenticated encryption.
   - `P2pWifiSyncService`: Host TCP server socket binding on random local port, peer client socket connection, 30s handshake timeout cap, 120s host idle auto-stop, and memory bounds enforcement.

3. **Add-Only Non-Destructive Merge**:
   - Merges incoming tasks based on natural primary keys (`date` + NFC-normalized `title`) without overwriting existing local data.
   - Preserves past-day Day-Lock constraints and handles time segments, recurrence rules, and mastery deck items.

4. **UI & Navigation**:
   - `P2pWifiSyncScreen`: Tabbed UI for Host Mode and Peer Mode with QR code / PIN pairing, interactive scope selector checkboxes, live status, and summary dialog.
   - Registered `/wifi-sync` route in `AppRoutes` and `app.dart`.
   - Added action icon in top app bar of `DailyListScreen`.

5. **Testing & Documentation**:
   - `P2pWifiSyncCrypto` unit tests verifying PBKDF2 key derivation (300,000 iterations), AES payload encryption/decryption, and HMAC authentication tag validation.
   - `P2pWifiSyncService` unit tests verifying payload building, memory bounds caps, NFC normalization, and non-destructive merge logic.
   - Updated `docs/unique_features_and_improvements.md` to mark section 3.14 as Implemented.
