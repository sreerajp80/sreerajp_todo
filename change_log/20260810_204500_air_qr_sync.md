# Change Log: 3.13 AirQR Optical Air-Gapped Animated QR Code Sync

**Plan Reference:** `plans/20260810_204400_air_qr_sync.md`
**Timestamp:** 2026-08-10 20:45:00

## Summary of Changes
Implemented **AirQR Optical Air-Gapped Animated QR Code Sync** for serverless, 100% offline data transfer between nearby devices using screen-to-camera optical QR code streams (5–25 FPS), Luby Transform (LT) Fountain codes with systematic parity frames, CRC32 checksum verification, and an interactive task import preview sheet.

## Detailed Changes

### 1. Dependencies & Manifest
- `pubspec.yaml`: Added `qr_flutter: ^4.1.0` and `mobile_scanner: ^7.2.0`.
- `docs/dependencies.md`: Documented `qr_flutter` and `mobile_scanner` as approved local offline dependencies.
- `android/app/src/main/AndroidManifest.xml`: Added `<uses-permission android:name="android.permission.CAMERA" />` (zero network permissions retained).

### 2. Core Entities & Data Services
- `lib/domain/entities/air_qr_frame.dart` [NEW]: Immutable entity representing systematic (`AIRQR|v1`) and Luby Transform (`AIRQR|LT1`) parity stream frames with CRC32 checksums.
- `lib/domain/entities/air_qr_progress.dart` [NEW]: Entity tracking reception progress state (block counts, live FPS counter, percentage ratio, completion status).
- `lib/data/services/air_qr_service.dart` [NEW]: Offline Fountain code encoder & belief propagation decoder solver over GF(2) XOR operations.
- `lib/data/services/air_qr_payload_service.dart` [NEW]: Serializes and deserializes tasks, timecards, and backup payloads into versioned AirQR payloads (`SREERAJP_TODO|v1|...`).

### 3. Presentation Layer & Navigation
- `lib/presentation/widgets/air_qr_share_dialog.dart` [NEW]: Animated QR stream sender dialog with FPS chip controls (5, 10, 15, 20, 25 FPS) and frame sequence progress.
- `lib/presentation/screens/air_qr_scan_screen.dart` [NEW]: Camera scanner screen using `mobile_scanner` with live stream progress overlay, block count ratio, live FPS counter, and torch toggle.
- `lib/presentation/widgets/air_qr_preview_sheet.dart` [NEW]: Interactive modal bottom sheet for previewing parsed AirQR tasks before merging.
- `lib/core/constants/app_routes.dart` & `lib/app.dart`: Registered `/air-qr-scan` route in GoRouter.
- `lib/presentation/screens/daily_list/daily_list_screen.dart`: Added AirQR Share Stream and AirQR Scan Camera action buttons in AppBar.
- `lib/presentation/screens/backup/backup_screen.dart`: Added AirQR Share Stream and AirQR Scan Camera buttons for air-gapped backup transfer.

### 4. Documentation
- `docs/unique_features_and_improvements.md`: Marked section 3.13 AirQR Optical Air-Gapped Animated QR Code Sync as Implemented ✅.

### 5. Automated Tests
- `test/domain/entities/air_qr_frame_test.dart` [NEW]: Unit tests for frame parsing and string formatting.
- `test/data/services/air_qr_service_test.dart` [NEW]: Unit tests for Fountain encoding, stream solver, CRC32 checksum verification, and recovery from packet loss.
