# Change Log: OCR Task Name and Description Scanner

**Date:** 2026-09-11
**Plan Reference:** `plans/20260911_195500_ocr_task_scanner.md`

## Summary of Changes
Implemented 100% offline, on-device OCR task scanning with advanced camera features and parsing rules.

### Key Additions & Updates:
1. **Offline OCR Parser (`lib/core/utils/ocr_task_parser.dart`):**
   - Parses raw OCR text into a task name (title) and description.
   - First non-empty line is parsed as the task name.
   - Detects separator line: space (blank/empty line), hash (`#`, `##`, `###`), or dashed line (`---`, `___`, `===`, `- - -`).
   - All text following the separator is assigned as the description.
   - Fallback if no explicit separator: line 1 is task name, lines 2..N are description.
   - Strips leading markdown header hashes from title (`# Task` -> `Task`).
   - Applies Unicode NFC normalization (`unicode_utils.nfcNormalize`) to both title and description.

2. **Domain Result Model (`lib/domain/entities/ocr_task_result.dart`):**
   - Immutable model holding `title`, `description`, `rawText`, `hasSeparator`, and `separatorType`.

3. **Advanced Camera Viewfinder & Controls (`lib/presentation/screens/ocr/ocr_scan_screen.dart`):**
   - Full-screen real-time camera viewfinder with dark translucent framing mask and document outline.
   - Interactive camera controls:
     - Torch / Flash toggle (Off, Torch, Auto).
     - Camera switch button (Rear / Front camera toggle).
     - Pinch-to-zoom gesture and quick zoom preset chips (`1x`, `2x`).
     - Tap-to-focus and exposure metering with animated reticle ring.
     - Central shutter button with haptic feedback.
     - Gallery image picker button (`FilePicker: FileType.image`) to scan existing photos/documents.
   - On-device ML Kit text recognition (`TextRecognizer`) with zero cloud/network access.

4. **Framing Guide Overlay (`lib/presentation/screens/ocr/widgets/ocr_camera_overlay.dart`):**
   - High-contrast corner brackets and guidance pill.
   - Visual divisions indicating "Task Name (Line 1)" and "Description (After space / # / ---)".
   - Animated tap-to-focus target ring.

5. **Interactive Review Sheet (`lib/presentation/screens/ocr/widgets/ocr_result_bottom_sheet.dart`):**
   - Bottom sheet allowing user review and editing of parsed title and description.
   - Real-time title uniqueness validation against target date.
   - Expandable raw OCR text section with one-tap clipboard copy button.
   - Action buttons: "Create Task" (immediately saves task), "Open in Full Editor" (pre-fills form for advanced attributes), and "Retake".

6. **Navigation & UI Entry Points:**
   - Added `/ocr-scan` route in `lib/core/constants/app_routes.dart` and `lib/app.dart`.
   - Added OCR scan button to `DailyListScreen` FAB stack.
