# Build number now shown on the About screen

Implements `plans/20260817_194651_about-screen-build-number.md`.

## What was wrong

`assets/config/app_config.json` holds `"build": "17"` and `AppConfig` parsed it into
a `build` field, but the About screen never displayed it. The value was loaded and
then dropped, so users saw the version but no build number.

## What changed

| File | Change |
|------|--------|
| `lib/l10n/app_en.arb` | Added `aboutBuildNumber` = "Build" with its `@` description |
| `lib/l10n/app_ml.arb` | Added the Malayalam label `ബിൽഡ്` |
| `lib/l10n/app_localizations.dart` | Regenerated by `flutter gen-l10n` |
| `lib/l10n/app_localizations_en.dart` | Regenerated by `flutter gen-l10n` |
| `lib/l10n/app_localizations_ml.dart` | Regenerated by `flutter gen-l10n` |
| `lib/presentation/screens/about/about_screen.dart` | Added a "Build" detail row |

The new row sits between "Version" and "Build date" in the details card. It uses the
`Icons.tag_rounded` icon and the same `_AboutDetailRow` widget as the other rows. It
is only drawn when `config.build` is not blank, so a config without a build value
looks the same as before.

Presentation layer and localization resources only. No domain, data, database, or
dependency change. Nothing touching offline behaviour, storage, or crypto.

## Checks run

- `flutter gen-l10n` — regenerated cleanly.
- `flutter analyze` — no issues found.
- `flutter test` — 283 tests, all passed.

## Notes for later

`lib/core/constants/app_version.g.dart` holds `kAppVersion` (`1.9.2+17`), generated
from `pubspec.yaml`, and is still used nowhere. The About screen reads version and
build from the JSON config instead, so the two can drift apart. Switching About to
the generated value was listed as "Option B" in the plan and was not done. It is
worth doing as its own change.
