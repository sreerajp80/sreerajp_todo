# Undo SnackBar layout fix

Implements plan `plans/20260903_053915_undo_snackbar_layout.md`.

## Problem

In the Malayalam UI the undo message box was tall and mostly empty. Flutter's
`SnackBar` drops the action button to a second line when the action label is
wider than 25% of the box (`actionOverflowThreshold`, default `0.25`). The long
Malayalam label "പഴയപടിയാക്കുക" always crossed that limit, and the always-on
close icon added more blank width.

## Changes

- `lib/presentation/shared/widgets/undo_status_snackbar.dart`
  - Added `actionOverflowThreshold: 1.0` so the undo button stays on the same
    line as the message.
  - Set `showCloseIcon: false` for this SnackBar only. Undo, the 5 second
    timeout, and swipe-to-dismiss still work.
  - Added `padding: EdgeInsets.only(left: 16, right: 8)` to balance the text
    and the button.
- `lib/presentation/shared/theme/app_theme.dart`
  - Added `actionOverflowThreshold: 1.0` to the app-wide `snackBarTheme`, so
    other SnackBars with long translated action labels do not wrap either.
    `showCloseIcon: true` stays for all other SnackBars.
- `lib/l10n/app_ml.arb`
  - Shortened the `undo` label from "പഴയപടിയാക്കുക" to "പഴയപടി".
- `lib/l10n/app_localizations_ml.dart`
  - Regenerated by `flutter gen-l10n`.

## Behaviour kept the same

Undo logic, the 5 second SnackBar timeout, and the persistent app-bar undo
button are unchanged.
